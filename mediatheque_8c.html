◆ lireEntier()

int lireEntier ( void )

Lit un nombre entier saisi par l'utilisateur, en redemandant tant que la saisie est invalide.

Remplace scanf("%d", ...) : si l'utilisateur tape autre chose qu'un nombre (une lettre par exemple), scanf échoue sans consommer la saisie, qui reste dans le buffer et fait boucler le programme à l'infini. Ici, toute la ligne est lue avec fgets puis convertie avec strtol, ce qui permet de détecter une saisie invalide et de redemander. La ligne étant lue en entier, aucun '
' ne reste dans le buffer : plus besoin d'appeler viderBuffer ensuite.

Returns
L'entier saisi, ou 0 si la fin du flux d'entrée est atteinte (EOF).

Fonctionnalité supplémentaire reprise de lireTexteNonVide (pseudo-code) : un titre, un auteur, une catégorie ou un nom d'emprunteur vide n'a pas de sens pour la médiathèque.
